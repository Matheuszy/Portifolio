# Matheus Carlos — Portfólio

Portfólio pessoal desenvolvido com React e Vite.

## Stack

- React 19
- Vite 6
- CSS puro

## Rodar localmente

```bash
npm install
npm run dev
```

## Estrutura

- `src/portfolioData.js`: todo o conteúdo (projetos, stack, certificações).
- `src/App.jsx`: seções e componentes.
- `src/index.css`: estilos globais.

## Deploy

```bash
npm run build   # gera dist/
npm run preview # testa o build localmente
```

Publique o conteúdo de `dist/` em qualquer host estático.
